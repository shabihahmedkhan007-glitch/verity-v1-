Nebius Hackathon Game Plan

Enter AI Hardware Engineer in the Coding & Agentic Engineering track. Build an agent (the brain) inside a website with a live dashboard (the window judges look through). Nemotron runs every agent role, Token Factory Sandboxes run the chip tools. Biggest risks: $50 of credits and undocumented sandbox limits.

Stage 2

How you get scored

Four criteria, equal weight, 1 to 5 each. Judges want "an agent that plans, writes, tests, and iterates on a real repo with minimal human input".

Technological implementation25%

Scored on how well you use Token Factory and the NVIDIA model. Nemotron must be the brain, not a side call.

Design25%

Live dashboard: agent steps, waveform, PPA chart across versions.

Potential impact25%

Chip design is slow and expert-only. Show hours of engineer work done in minutes.

Quality of the idea25%

The novelty is the PPA loop: the agent makes the chip faster and smaller, not just correct.

Dots show our expected strength per criterion, not official weights.

App or agent?

Both: an agent inside a website

The agent does the chip designer's job. The website lets judges watch it happen, with nothing to install.

The brain · agent

Does the work by itself

  • Reads the request in plain English
  • Writes the chip code (Verilog)
  • Tests it, fixes its own mistakes
  • Measures speed, size, power
  • Tries versions, keeps the best
Thinks with NVIDIA Nemotron · tools run on Nebius

Judges open a link and watch

  • The code, and what changed between versions
  • Signal graphs of the chip working
  • A picture of the finished layout
  • A chart of each version getting better

Next.js + FastAPI: how it fits

Keep the stack you know. One container, one URL, all on Nebius.

Backend · FastAPI
  • OpenAI Python SDK → Token Factory (api.tokenfactory.nebius.com/v1)
  • contree_sdk: chip tools image, a branch per version
  • Live stream: built-in SSE in recent FastAPI, or sse-starlette
  • Tavily client
  • Saved demo run = a JSON file of events, replayed
Frontend · Next.js
  • Tailwind (+ shadcn/ui if you use it)
  • @monaco-editor/react with dynamic(..., {ssr:false})
  • Surfer viewer in an iframe, VCD by URL
  • netlistsvg in the browser
  • Any chart library you know (e.g. Recharts)
  • Browser EventSource for the live stream
Skip:database (JSON / SQLite is enough)user accounts (one token for judges)LangGraph (plain loop is simpler)
Safety trick 1

Saved run

One full run is recorded. Judges replay it instantly, no waiting, no credits spent.

Safety trick 2

Capped live runs

Live runs on a few preset requests, with a spending limit per run. Protects the $50.

Sandbox limits undocumented

high

Evidence

Sources & limits

Could not verify

  • Token Factory prices come from a third-party listing (mastra.ai); Nebius's own price page needs JavaScript and did not load.
  • Sandboxes "free in beta" is from a search snippet only.
  • Sandbox CPU, RAM, disk, max timeout and runtime internet access are not documented anywhere we found.
  • Nemotron 3 Ultra's 97.1% CVDP score is NVIDIA's own claim, in its own harness, compared only with open models.
  • Builders & Brews event dates did not render on Luma; the resources page says Sep 9 to Oct 13.
  • $0.03 per step, ~1,500 steps and ~50 runs are our estimates (about 20k input + 4k output tokens per step with Ultra, ~30 steps per run).
  • Judging window "Dec 1-15" comes from one forum post. Hosting cost $100-250 is our estimate; whether hackathon credits cover Nebius compute is an open forum question.
  • Surfer's EUPL license should allow embedding the unmodified viewer; not legally confirmed. OpenROAD's new web image export was merged Sep 22 2026, so pin the version.
  • "Past winners were mostly web apps" is based on AWS AI Agent and GitLab 2026 winners, not a full survey. Vercel was not checked as a host.
